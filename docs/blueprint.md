# **App Name**: Ruta Inteligente

## Core Features:

- Tareas (Tasks): Display list of tasks for user, including bids, won bids, and moderator messages.
- Viajes Nuevos/Abiertos (New/Open Trips): Show new trips available for bidding, trips already seen, and trips with offers made.
- Licitaciones Ganadas (Awarded Bids): Allow users to confirm and accept awarded trips.
- Viajes en Progreso (Running Trips): Display trips currently in progress and those completed within the last 24 hours.
- Búsqueda de Embarques (Shipment Lookup): Allow users to search trips by shipment ID.
- Tiempos Estimados (Estimated Times): Register estimated times such as arrival to origin, destination, loading/unloading within each trip.
- Rastreo (Tracking): Show the live location of the unit, updating every hour.

## Style Guidelines:

- Primary color: Deep Blue (#3F51B5) to evoke trust and reliability in logistics.
- Background color: Light Blue (#E8EAF6), a desaturated version of the primary, for a calm and professional backdrop.
- Accent color: Purple (#7E57C2) to highlight interactive elements and important updates.
- Body and headline font: 'PT Sans' for readability and a modern feel, suitable for both headlines and body text.
- Use clear, consistent icons to represent trip status, cargo type, and navigation actions. Icons should be designed with sufficient contrast for accessibility.
- Employ a bottom tab navigation for main modules: Tareas, Viajes en Progreso, Rastreo, and Perfil. Utilize cards to display trip information within each module.
- Subtle loading animations and transitions to enhance user engagement. Confirmation dialogs should smoothly appear and disappear.
